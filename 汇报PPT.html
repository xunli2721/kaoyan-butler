关键技术决策

决策方案理由效果
意图识别 三层架构 性能+成本+安全 正则命中40%，AI准确率>90%
数据存储 LocalStorage 零成本+隐私保护 无需数据库，数据在用户端
意图路由 分发到专用处理器 职责分离+可扩展 4个处理器独立维护
AI模型 DeepSeek API 价格低+OpenAI兼容 约1元/百万token

问题与协作经验

遇到的问题

  • 学习记录提取："背单词两小时"无法识别
    → 扩展关键词库，提取率70%→90%
  • WebSocket断连：网络波动导致断开
    → 添加自动重连机制（5秒间隔）
  • 面板切换冲突：计划/统计同时打开
    → 设计Tab切换互斥机制

Agent协作经验

  • 精确指令：模糊指令导致返工，精确指令一次到位
  • 分步验证：每层独立测试，问题定位快速
  • 场景特化：通用方案需针对考研定制

协作方式
